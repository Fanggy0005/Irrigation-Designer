# ขอบเขต v1: ออกแบบระบบน้ำสวนไม้ผล

ผู้ใช้หลักคือช่างหรือผู้ออกแบบระบบน้ำมืออาชีพ ผลลัพธ์ที่ต้องได้คือแบบบนแผนที่ ตัวเลขชลศาสตร์ที่ตรวจสอบได้ และรายการวัสดุ

**ใช้ฟรีทั้งหมด:** สมัครและล็อกอินแล้วใช้ได้ทุกฟีเจอร์ ไม่มีแพ็กเกจ ไม่มีระบบจ่ายเงิน และไม่จำกัดจำนวนโครงการ สิทธิ์ที่ต้องตรวจมีแค่ "ล็อกอินอยู่หรือไม่" กับ "เป็นเจ้าของโครงการนี้หรือไม่"

## ขั้นตอนการทำงาน (ทั้งหมดอยู่ในหน้า editor หน้าเดียว)

1. **โครงการ**: ตั้งชื่อ ค้นหาตำแหน่งด้วย Photon แล้วปักจุดแหล่งน้ำ
2. **พื้นที่**: วาดขอบเขตแปลง (polygon) และพื้นที่ที่ปลูกไม่ได้ เช่น บ่อ บ้าน หรือถนน
3. **การปลูก**: เลือกชนิดพืช (ระยะต้น × ระยะแถว และปริมาณน้ำ ลิตร/ต้น/วัน) กับมุมแนวแถว ระบบสร้างจุดต้นให้อัตโนมัติ แล้วผู้ใช้เพิ่มหรือลบทีละต้นได้
4. **หัวจ่าย**: กำหนดสเปกหัวจ่าย (อัตราไหล L/h ที่แรงดันใช้งาน และจำนวนหัวต่อต้น)
5. **โซน**: วาดเองหรือให้ระบบแบ่งตามอัตราไหลสูงสุดต่อโซน แล้วกำหนดเวลารดน้ำของแต่ละโซน
6. **ท่อ**: วาดท่อเมน (แหล่งน้ำ → โซน) และท่อเมนย่อยในแต่ละโซน ท่อแขนงสร้างตามแนวแถวให้อัตโนมัติ และผู้ใช้แก้ไขได้
7. **ชลศาสตร์**: คำนวณ head loss ตามเส้นทางวิกฤตของแต่ละโซน แรงดันปลายท่อ ความเร็วน้ำ และความแปรผันของแรงดันในโซน ระบบเสนอขนาดท่อให้ และผู้ใช้เปลี่ยนเองได้
8. **ปั๊ม**: แสดง duty point (Q และ TDH ของโซนที่หนักที่สุด) กับกำลังโดยประมาณ ยังไม่เลือกรุ่นปั๊ม
9. **รายงาน**: แผนผังบนแผนที่ ตารางชลศาสตร์แยกตามโซน และรายการวัสดุ (ท่อแต่ละขนาด/class คิดเป็นเมตรและจำนวนม้วน, หัวจ่าย, ข้อต่อโดยประมาณ) สั่งพิมพ์หรือบันทึกเป็น PDF ผ่านเบราว์เซอร์

## ไม่อยู่ใน v1

ราคา/ใบเสนอราคา, ระบบจ่ายเงินหรือแพ็กเกจใด ๆ, AI chat, โหมดพืชไร่/โรงเรือน/สวนบ้าน, ดึงความสูงพื้นที่อัตโนมัติ (v1 ให้กรอกความต่างระดับเอง), ทำงานเป็นทีม, 3D และ import KML

## ข้อมูลอุปกรณ์

ใช้สเปกมาตรฐานทั่วไปเท่านั้น เช่น ขนาดท่อ PE/PVC แต่ละ class และสเปกหัวจ่ายทั่วไป ไม่ผูกยี่ห้อและไม่มีราคา ค่าทั้งหมดคำนวณจากสูตร ห้ามนำ catalog, ราคา หรือข้อมูลใด ๆ ของบริษัทเดิมมาใช้

## หลักการ

- **สูตรอยู่ที่เดียว** คือ `resources/js/domain/` เป็นฟังก์ชันล้วน ไม่ import React หรือ Leaflet และทุกสูตรมี test เทียบกับตัวเลขที่คำนวณมือหรือจากเอกสารอ้างอิง
- **หน่วยเดียวทั้งระบบ** (ดู `domain/units.ts`): ความยาว m, เส้นผ่านศูนย์กลางภายใน mm, อัตราไหล L/h, แรงดันเป็น m (head) แปลงหน่วยเฉพาะตอนรับค่าจากผู้ใช้และตอนแสดงผล
- **โปรเจกต์คือ object ก้อนเดียว** อยู่ใน store ก้อนเดียว (`editor/store.tsx`) บันทึกอัตโนมัติลงคอลัมน์ JSON `projects.design` ห้ามใช้ localStorage ส่งข้อมูลระหว่างหน้า รูปแบบข้อมูลกำหนดที่ `domain/project.ts` (zod) ที่เดียว ทุก field มีค่า default จึงเพิ่ม field ใหม่ได้โดยแบบเก่ายังเปิดได้ และเลข `version` ใน JSON เปลี่ยนเฉพาะเมื่อต้องแปลงรูปแบบข้อมูลเดิม
- **ไม่เก็บค่าที่คำนวณได้** เช่น จุดต้นไม้ อัตราไหล หรือ head loss ทุกค่าคำนวณใหม่จาก `Project` ทุกครั้ง
- **แผนที่ใช้ Leaflet ตัวเดียว** ใช้ภาพดาวเทียม Esri, OSM สำหรับแผนที่ถนน และค้นหาสถานที่ด้วย Photon (จำกัดเฉพาะในไทย) ส่วนการวาดใช้ Leaflet-Geoman
- ไฟล์หนึ่งไม่ควรเกินประมาณ 300 บรรทัด, TS strict, ห้ามใช้ `any`

## Data model

ดูรายละเอียดได้ที่ `domain/project.ts` field ที่เพิ่มในอนาคตต้องมีค่า default

```ts
type Project = {
    version: 1;
    site: { waterSource: LatLng | null; sourceElevationM: number }; // ระดับพื้นที่ปั๊ม
    boundary: LatLng[];
    exclusions: LatLng[][];
    planting: {
        plantName: string;
        spacingM: number;
        rowSpacingM: number;
        rowBearingDeg: number; // 0 = แถวเหนือ–ใต้, 90 = ตะวันออก–ตะวันตก
        staggered: boolean;
        edgeSetbackM: number;
        removed: LatLng[]; // ตำแหน่งต้นที่ลบ (จับคู่กับต้นที่สร้างภายในระยะ 1/4 ของระยะปลูก)
        added: LatLng[];
        waterLPerDay: number; // ลิตร/ต้น/วัน, 0 = ยังไม่กรอก
    };
    emitter: { flowLph: number; pressureM: number; perPlant: number };
    zones: { id: string; name: string; polygon: LatLng[]; runMinutes: number | null; elevationM: number }[]; // runMinutes null = คำนวณจาก waterLPerDay
    pipes: { id: string; kind: 'main' | 'submain' | 'lateral'; path: LatLng[]; specId: string | null }[]; // เฉพาะท่อที่วาดเอง, specId null = ขนาดที่ระบบเสนอ
    laterals: { removed: LatLng[] }; // จุดกึ่งกลางของท่อแขนงอัตโนมัติที่ลบ
    settings: {
        maxZoneFlowLph: number;
        minorLossPct: number;
        maxVelocityMps: number;
        maxPressureVariationPct: number; // % ของแรงดันใช้งานของหัวจ่าย
        lateralSpecId: string | null; // ขนาดของท่อแขนงอัตโนมัติทุกเส้น
    };
    pump: { suctionLiftM: number; suctionLossM: number; efficiencyPct: number };
};
```

ท่อไม่เก็บ `zoneId` เพราะโซนของท่อหาได้จากตำแหน่ง (โซนที่ท่อผ่านยาวที่สุด, `domain/zones.ts`) ถ้าแบ่งโซนใหม่ ท่อจึงไม่ชี้ไปยังโซนที่ไม่มีอยู่แล้ว

    - `hydraulics/designHydraulics.ts`: หาอัตราไหลก่อน (ไม่ขึ้นกับขนาดท่อ) แล้วเสนอขนาดท่อแต่ละเส้นจากอัตราไหลสูงสุดเมื่อเปิดโซนใดโซนหนึ่ง แล้วคำนวณแต่ละโซน: แรงดันที่ปั๊มต้องจ่าย, การสูญเสียตามเส้นทางวิกฤตแยกเมน/เมนย่อย/แขนง, ช่วงแรงดันหัวจ่ายและ % ความต่าง, ความเร็วสูงสุด, แรงดันเกินชั้นท่อ และ duty point ของปั๊ม (โซนที่ใช้กำลังมากที่สุด)

## ตัดสินใจแล้ว

- **กฎการวางท่อแขนงอัตโนมัติ (M3):** แถวละหนึ่งเส้น แยกซ้าย–ขวาของจุดที่ท่อเมนย่อยของโซนตัดผ่านแถว และวิ่งไปถึงต้นสุดท้ายในโซนฝั่งนั้น ต้นแต่ละต้นต่อกับจุดตัดที่ใกล้ที่สุดตามแนวแถว แถวที่ท่อเมนย่อยไม่ผ่านจะไม่มีท่อแขนง ท่อแขนงที่วาดเองได้ต้นที่อยู่ห่างไม่เกินครึ่งหนึ่งของระยะต้นหรือระยะแถว (ค่าที่น้อยกว่า) ไปก่อน ต้นที่เพิ่มเองไม่อยู่บนแถว จึงต้องวาดท่อแขนงไปหา แถวคู่ใช้ท่อร่วมกันยังไม่รองรับ (ถ้าต้องการให้วาดเอง)

- **ตารางขนาดท่อ (M4):** แต่ละชุดท่อใช้ค่าจากตารางของแหล่งเดียว ห้ามผสมค่าจากหลายตาราง ที่มาและการตรวจเทียบอยู่ใน `docs/research/pipe-sizes.md`
    - PVC: มอก. 17-2561 (ฉบับปัจจุบัน แทน 17-2532 ที่ยกเลิกแล้ว) ชั้น 5, 7, 8.5, 10.5, 13.5 ขนาด 18–200 จากตัวเต็มของ สมอ. ใช้ D และ e ค่ากลาง ชั้นท่อคือความดันระบุที่ 27 °C ชื่อขนาดใช้ตามมาตรฐาน ("ขนาด 25") เพราะขนาดเป็นนิ้วไม่ได้อยู่ในตัวมาตรฐาน
    - PE แรงดัน: PE100 SDR 11/13.6/17/21/26 จาก catalog S-lon (อ้าง ISO 4427) เพราะเข้าถึงตัวมาตรฐานไม่ได้ ความหนาเป็นค่าต่ำสุด PN ที่ 20 °C ถ้าได้ตัวเต็ม มอก. 982-2556 ควรเปลี่ยนมาใช้
    - ท่อแขนง: ISO 8779:2001 Table 1 (ฉบับที่ถูกแทนแล้ว ฉบับปัจจุบันต้องซื้อ) ทั้ง 7 ชุด ความหนาเป็นค่าระบุ
    - ระบบเสนอขนาดจาก PVC 8.5 สำหรับท่อเมนและเมนย่อย และ PE40 PN 4 สำหรับท่อแขนง
    - ค่า C: USDA NRCS NEH Part 623 Table 7-23 ตามเส้นผ่านศูนย์กลางภายใน (130 ถึง 26 มม., 140 ต่ำกว่า 76 มม., 150 ตั้งแต่ 76 มม.)
